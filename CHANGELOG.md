All `@awthaq/*` packages are versioned in lockstep (a fixed group in
[`.changeset/config.json`](./.changeset/config.json)), so their version
numbers always match even where a given release didn't touch every
package's own source.

To add a changelog entry for your change, run `pnpm changeset` — see
[CONTRIBUTING.md](./CONTRIBUTING.md) for details.
