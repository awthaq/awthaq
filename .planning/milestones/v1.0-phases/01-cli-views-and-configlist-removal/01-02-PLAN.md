<objective>
Route every `awthaq plugin list` view through one views module that resolves `--format` and the global `--json` once, with output identical to today (CLI-01).

Purpose: `Plugin.show` holds four hand-copied JSON/text branches plus a graph-only dot branch; a fifth view could forget the `--format` check (Pitfall 19). One resolver plus an explicit override on `Output.report` makes the precedence a single function.

Output: new `packages/cli/src/PluginViews.ts`; `Output.report` gains an optional `{ json }` override; `Plugin.ts` declares five view descriptors and `show` becomes a selector. The Wave 0 matrix proves the output did not move.
</objective>
