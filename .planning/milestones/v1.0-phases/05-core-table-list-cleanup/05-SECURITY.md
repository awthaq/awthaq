- **N2 (mutation evidence is from the record).** The one-literal mutations for the pins (`05-BASELINE.md:219`) and for the drift guard (`05-03-SUMMARY.md`, `05-REVIEW-FIX.md` IN-05) were not re-run here because source is read-only. The negative tests at `CoreTables.test.ts:55-72` are live and pass, which re-proves the guard's comparison can report a stray table.
- **N3 (limit of a control, low).** `freeze` is shallow: the `tables` array and each `sealed` array are frozen, but the entry objects in `tables` and the `CoreSealedColumns` declaration objects inside `sealed` are not. No consumer in `packages/*/src`, `features` or `examples` reads `tables` entries (the only source uses are `isStamped`, the two `TenantScope` aliases and `LaggingReplica`), and every exported list is built from the module-private `declared`, so mutating an entry cannot reach RLS coverage, `isStamped` or the replica list. The README, the changeset and the field's doc comment qualify it as the test replica's mirror list, and nothing but `LaggingReplica` consumes it, so the routing source stays ADR-EA-024 (no diff under `spec/decisions`). Consider adding "test" in the next spec revision.
- **N5 (informational).** Review finding IN-06 (`owner`, `sealed`, `tables`, `names` have no source consumer) was skipped by the fixer as required by CAT-01. It is a necessity finding, not a security one; the unused fields do not widen any surface.
